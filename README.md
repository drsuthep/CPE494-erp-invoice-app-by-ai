# CPE494-erp-invoice-app-by-ai
ERP Invoice application generated and iteratively developed by a multi-agent AI coding team.

## Day 1 Setup (Windows PowerShell)

Run these commands from this repository root:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install django
```

Verify Django installation:

```powershell
python -c "import django; print(django.get_version())"
```
